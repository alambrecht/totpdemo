How it works
  1. The server creates a random 160-bit shared secret and shows it as a QR code (Base32 encoded).
  2. Your phone and the server both compute counter = floor(unix_time / 30).
  3. Each side calculates HMAC-SHA1(secret, counter) and truncates it to 6 digits.
  4. Same secret + same time = same code. No network connection between phone and server is needed.
  5. The server accepts the previous and next 30s window too, to tolerate small clock drift.
